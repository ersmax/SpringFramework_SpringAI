This repository contains practical projects to practice Java Spring Boot framework.

---
To compile inside the source program or source code folder:
```Java
PS D:\Java\Udemy\JavaSpringFrameworkBootSpring\Projects\Spring\src\Section2_CoreJava\L8_CodeSetup> javac main.java
```
To compile inside the main folder:
```Java
PS D:\Java\Udemy\JavaSpringFrameworkBootSpring\Projects\Spring\src> javac .\Section2_CoreJava\L8_CodeSetup\main.java 
```

To run the compiled class (run the bytecode or object code) from the source program folder:
```Java
PS D:\Java\Udemy\JavaSpringFrameworkBootSpring\Projects\Spring\src\Section2_CoreJava\L8_CodeSetup> java -cp ../.. Section2_CoreJava.L8_CodeSetup.main
```

To run the compiled class from the main folder:
```Java
PS D:\Java\Udemy\JavaSpringFrameworkBootSpring\Projects\Spring\src> java Section2_CoreJava.L8_CodeSetup.main 
```
